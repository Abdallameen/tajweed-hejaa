# منصة أحكام التجويد الأساسية من خلال الهجاء القرآني

موقع تفاعلي خفيف وسريع متوافق مع الجوال ومخصّص للربط مع **المواسح الضوئية (QR Codes)** في كتاب **أحكام التجويد الأساسية من خلال الهجاء القرآني**.

## المميزات
- **ماسح ضوئي لأول الكتاب (الإنجازات):** يفتح صفحة الإنجازات والتعريف بالدورة وإحصائياتها والفئات المستهدفة، مع تبويبين للفيديو.
- **ماسح ضوئي لكل درس وتتمّة (23 درسًا وتتمة):** كل صفحة تحتوي على تبويبين واضحين:
  1. **شرح حضوري**
  2. **شرح عن بُعد**
  بالإضافة إلى خلاصة القاعدة التجويدية والتنقل السريع بين الدروس.
- **صفحة المواسح الضوئية (`?p=qr`):** تعرض جميع الـ 24 ماسحًا مع زر تحميل (PNG) وزر طباعة مباشرة، كما توجد جميع صور الـ QR جاهزة في مجلد `qr-codes/`.

## طريقة إضافة روابط الفيديوهات
افتح ملف `data.js` وضع رابط الفيديو داخل الحقلين لكل درس:
```js
inPersonVideo: "https://youtu.be/XXXXXXX", // رابط الشرح الحضوري
remoteVideo:   "https://youtu.be/YYYYYYY", // رابط الشرح عن بُعد
```
يدعم الموقع تلقائيًا روابط **YouTube** (العادية والمختصرة وShorts) و**Google Drive** و**Vimeo** وملفات **MP4**.
